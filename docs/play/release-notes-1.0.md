# Release notes: 1.0 (versionCode 1)

"What's new" for the first upload, at most 500 characters per language
(`python3 scripts/check-listing.py` checks). Paste each block into Play
Console's release notes under its language tag.

### Release notes (en-US)

```text
First release of Bukin Magnifier: a magnifying glass with the LED light.
• Live magnifier with zoom by lens ring, pinch or volume keys
• Auto focus, tap to lock, manual focus where the camera allows
• Freeze a sharp photo, then zoom and move around in it
• Normal, high contrast, inverted and yellow-on-black colours
• Save or share a frozen picture
• No ads, no internet permission
```
