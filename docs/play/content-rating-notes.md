# Content rating (IARC questionnaire): how to answer honestly

Play Console → **App content** → **Content rating** → Start questionnaire. The
owner fills it in; these are the facts to answer from. The questionnaire's
exact wording changes from time to time: read each question, and answer from
the facts below, not from this file's paraphrase.

## Category

**All other app types** (a utility). Not a game, not social networking, not a
news, reference or browser app.

## The facts

| Topic the questionnaire asks about | Bukin Magnifier | Answer |
|---|---|---|
| Violence, blood, fear, sexuality, nudity, crude humour, bad language | None in the app's own content. The app shows only what the user's camera sees. | No |
| Drugs, alcohol, tobacco | None. ("Medicine leaflets" in the listing is an example of what to read, not content.) | No |
| Gambling, simulated gambling, loot boxes | None | No |
| Users interact or exchange content **with other users** in the app | No chat, accounts, posts or uploads. Share only opens Android's share sheet, which hands one picture to another app the user picks; the app itself has no way to reach other users. | No |
| Shares the user's **location** with other users | No location permission; nothing is sent anywhere. | No |
| **Purchases** of digital goods | No in-app purchases, no billing library. | No |
| Unrestricted internet, **web browser** or search engine | No internet permission. About opens the privacy policy in the user's own browser: the app is not a browser. | No |
| Ads | None | No |
| Personal information collected | None (see `data-safety.md`) | No |
| User-generated content shown to others | None | No |

## Expected result

All "No" answers to a utility normally give the lowest rating everywhere
(for example IARC 3+, PEGI 3, ESRB Everyone, USK 0). Play shows the actual
rating after submission: record it in the owner checklist.

If a question asks whether the app "allows sharing" in a broader sense (for
example "can users share photos?"), the honest answer is that the app only
hands a picture to the system share sheet at the user's request; if the
question counts that, answer **Yes** rather than guess. It doesn't change the
rating of a utility without user-to-user features.
