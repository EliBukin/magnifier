# Bukin Magnifier

זכוכית מגדלת חינמית ל־Android: המצלמה האחורית של הטלפון, מוגדלת, עם פנס
ה־LED. לקריאת אותיות קטנות, תוויות, עלוני תרופות ותגיות מחיר.

## מה היא עושה

- **זכוכית מגדלת חיה:** המצלמה האחורית ממלאת את המסך ונפתחת מיד.
- **הגדלה:** סיבוב טבעת העדשה בתחתית המסך, צביטה, או מקשי עוצמת הקול.
- **פנס:** פנס ה־LED של הטלפון, הדלקה וכיבוי בהקשה אחת.
- **הקפאה:** תמונה חדה שאפשר להגדיל ולהזיז.
- **צבעים:** רגיל, ניגודיות גבוהה, צבעים הפוכים, וצהוב על שחור.
- **בהירות ומיקוד:** הבהרה או החשכה של התמונה. המיקוד אוטומטי; הקשה נועלת
  אותו, ובטלפונים שהמצלמה שלהם מאפשרת זאת אפשר גם לכוון אותו ידנית.
- **שמירה או שיתוף** של תמונה מוקפאת.
- **נוחה לשימוש:** כפתורים גדולים בהישג אגודל אחד, תוויות TalkBack לכל
  פקד, עברית ואנגלית.

דורשת Android 7.0 ואילך ומצלמה אחורית.
